# アバターの体 (body.webp) の出どころとライセンス

- 元の 3D の人体: MakeHuman の base mesh (`makehuman/data/3dobjs/base.obj`) と体型の target
  (`targets/macrodetails/universal-female-young-averagemuscle-minweight.target` を 1.0、
  `targets/macrodetails/height/female-young-averagemuscle-minweight-maxheight.target` を 0.6)。
  髪は体の頭の面を押し出した殻、下着の層は base mesh の `helper-tights`
- 出どころ: https://github.com/makehumancommunity/makehuman (`LICENSE.md` の「C. The license for the bundled assets」)
- ライセンス: **CC0 1.0 Universal** (base mesh・target は MakeHuman に同梱の素材で、CC0 で公開されている。`LICENSE.ASSETS.md`)
- 描き方: Blender 5.1.1 (Cycles、正面の正投影、背景は透明) で 400×800 に描き、WebP にした (2026-11-19、wakuwaku factory)。
  肌・髪・布は Blender の手続きの材質 (画像の texture は使っていない)
- 実在の人の写真・顔写真は使っていない。この絵も CC0 として扱ってよい
