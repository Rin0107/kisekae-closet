# kisekae-closet — デザインシステム

持ち主: **designer**。画面はここに書いたものだけで作る。変えるときは、わざと変えて理由を `## 変えたこと` に書く。

## トークン
`src/style.css` の `:root` に CSS 変数で置く。部品は生の値 (色・大きさ・余白) を書かず、変数だけを使う。
- 色 (いちごミルク): 地 `--c-bg` #fff7f9・面 `--c-surface`/`--c-surface-2`・文字 `--c-text` #3d2a30・弱い文字 `--c-muted`・強調 `--c-primary-strong` #b53b5e (白い字とのコントラスト 4.5 以上)・やさしいピンク `--c-primary-soft`・失敗 `--c-danger`。
  ゲージ `--c-cold`/`--c-ok`/`--c-hot`、カレンダーの近さ `--c-same`/`--c-near`、キラッ `--c-gold`
- 文字: system-ui (外から字を読まない)。段は `--fs-s` 0.8125 / `--fs-m` 1 / `--fs-l` 1.25rem
- 余白: `--sp-1` 0.25 / `--sp-2` 0.5 / `--sp-3` 1 / `--sp-4` 1.5rem
- 角・影・動き: `--radius` 16px・`--radius-s` 10px・`--shadow`・`--ease` (Material 3 の emphasized)・`--dur` 240ms。prefers-reduced-motion では動かさない
- 大きさ: タップは `--tap` 48px 以上。アバターの台は `--stage-w` 200px × `--stage-h` 400px、幅 768px 以上では 280px × 560px (#34)。今日の画面は、スマホの幅 (360px) でも台 (200×400px、縮めない・左) と服の棚 (右) の 2 列。棚は台と同じ高さで、服の列 (正方形のタイル 1 列、着ている服は濃い枠と右上のチェック) と、右端の種類のレール (`--rail-w` 48px、形の絵 `KindIcon`。名前は読み上げ用の文字と title) に分ける。服の列だけが縦に流れ (持ち主 2026-11-21 の案 B)、アバターは見えたまま。その下にラベル・暖かさゲージ・これに決めた (Rin0107/kisekae-closet-archive#50)。その幅の中では**固定** (どの画面でも一番大きい。中身で縮めない)

## テーマ
`src/theme.ts` の `THEMES`。いちごミルク (既定、`:root` と同じ値)・ミントソーダ・ラベンダー・ミルクティー。
色のトークン (`THEME_TOKENS`) だけを `:root` に上書きする。大きさ・余白・台の大きさは変えない。
字と地の組 (`TEXT_PAIRS`) は、どのテーマでも 4.5:1 以上 (`tests/unit/theme.test.ts`)。新しいテーマも同じ検査を通す。

## 部品
- **アバターの台** (`Stage`): 正面に固定した体の絵 (CC0 の MakeHuman の人体を Blender で描いた `public/avatar/body.webp`、400×800、背景は透明。出どころは `public/avatar/LICENSE.md`) に、切り抜いた服の写真を種類ごとの場所 (`SLOTS`) に重ねる。写真は曲げない。トップス・ワンピース・アウター・ボトムスは**幅で合わせ、縦は写真のまま** (体の絵を測った目印 `BODY` に対し、袖を除いた身ごろが胴の下着の幅と首元を覆う幅。#26)。ボトムスは丈を先に決め、裾が足首に届く幅にする (腰を覆う 46%〜太すぎない 60%、`place`、#33)。アウターはトップスより一回り大きく少し下から置き、中の服の襟元がのぞく (#33)。くつは 2 足の写真を左右の半分に切り分け、それぞれの足に履かせる (`shoeFeet`、#32)。片足の箱は足より一回り大きく (`FOOT_BOX` 16×10%、細くても足の幅を下回らない)、ボトムスの裾より前に重ねる (長ズボンでも甲が見える、#39)。トップス・アウターは写真を左の袖・身ごろ・右の袖に切り分け (`pieces`)、切れ目は写真ごとに身ごろの端を測って決め (`bodiceEdge`、縁のにじみを袖に入れない)、袖の向き (付け根の真ん中→袖の重心、`measureSleeve`) が腕の向き (`ARM_ANGLE`、約 35 度) にそろうように回す (`sleeveTurn`、-70〜45 度。外へは付け根の真ん中、内へは肩の縫い目を中心に。袖の先は台の外に出さない。写真は曲げない、#37 #44)。袖は身ごろの下に描き、影は服 1 枚分の入れ物 (`wear-cut`) に付ける (継ぎ目に線を出さない、#44 #47)。中にトップスかワンピースを着ていれば、アウターは前身ごろを左右に分けて前を開ける (`OPEN_GAP`、#38)。こものは箱に収める。服が届くまでは服の場所に淡い形 (`wear-pending`) を出し、下着姿を見せない (#28)。今日の画面とカレンダーの下見で使う
- **ラベルの行** (`LabelRow`): 台の下の高さ固定 (32px) の 1 行。3 つまで、残りは「+N」。台には重ねない
- **暖かさゲージ** (`GaugeView`): 寒い・ちょうどいい・暑いの帯とつまみ。数字は出さない。服が届くまではつまみを出さず「服を読んでいます…」 (#28)。帯の言葉 (寒い・ちょうどいい・暑い) と「暖かさ: ○○」はスマホの幅でも折り返さない (`nowrap`)。その下に帯ごとの一言 (`ADVICE`、20 文字以内。寒い=「少し寒そう。もう1枚重ねよう」・ちょうどいい=「ちょうどいい。このままでOK」・暑い=「少し暑そう。1枚減らそう」)。読み込み中は出さない
- **棚** (クローゼット): 種類のタブ (トップス・ワンピース・ボトムス・アウター・くつ・こもの。ワンピースにも自分のタブ、#35) と服のカード。カードはタップで着る・台までドラッグで着る
- **キラッ**: 着替えたとき台の上で光る 3 つの星
- **スタンプ**: コーデを決めると台の右上 (頭の横の空いたところ。くつ・服に重ねない、#47) に「決めた!」。天気が読めないうちに決めた日は、天気が読めたら保存すると一言添え、カレンダーのスタンプを淡くする (#46)。カレンダーの決めた日 (今日まで) には ♥、先に決めておいた日には ♡
- **先の日の帯** (`plan-bar`): 先の日のコーデを決めているあいだ、今日の画面の上に「11月20日のコーデを先に決めています (予報)」と「今日に戻る」
- **設定** (`Settings`): テーマ・ログアウト・書き出し・アカウントの削除は、クローゼットの下の『設定』から開く (閉じているあいだは出さない。今日・カレンダーの画面には出さない。`aria-expanded`)。服をしまう・見るを主役にするため
- **テーマの選択** (`ThemePicker`): 『設定』の中。色の見本つきのボタン 4 つ (押している状態は `aria-pressed`)
- **着ている服**: 棚の着ている服 (押されている) をもう一度押すと脱ぐ (キラッとしない、#45)。ドラッグで台に落としたときは着たまま
- **切り抜けなかった写真**: 背景がほとんど残った写真 (白い背景の白い服など) は、しまう前に知らせて「撮り直す」を出す (このまましまうこともできる、#47)
- **登録の工程**: 服をしまう欄は、最初からトップスが選ばれていて、枠と写真のボタンがすぐ出ている。しまったあとも種類はそのまま (続けて同じ種類を撮れる)。種類のボタンで変える。撮った写真の下見の枠は、スマホの幅いっぱい近く (`min(80vw, 320px)`) の正方形で、切り抜きは送る写真と同じ長辺 1024px で作る (Rin0107/kisekae-closet-archive#49)
- **写真のボタン** (`.photo-buttons`): 「カメラで撮る」(主役の色、カメラの絵、`capture="environment"`) と「写真から選ぶ」(写真の絵) の 2 つの大きな丸いボタン (48px 以上、文字は折り返さず入らなければ次の行へ)。ブラウザのファイルの欄は `.visually-hidden` で隠し、label を押すと開く (読み上げ・フォーカスは届く)。絵は aria-hidden
- **カレンダーのマス**: 日・天気のアイコン・最高気温・湿度・スタンプ。背景色で今日との近さ (凡例つき)
- **タブバー**: 下に固定。今日・クローゼット・カレンダー
- ボタン: `primary` (主な 1 つ)・`ghost` (それ以外)・押している状態は `aria-pressed`/`aria-selected` で同じ見た目

## 状態
- からっぽの棚: クローゼットの画面の棚に服がなければ、「ワンピースはまだありません」と「ワンピースを撮る」ボタン。押すと種類をその棚に合わせ、撮る欄まで動く (Rin0107/kisekae-closet-archive#49)
- 種類のチップ: しまう服の種類は、枠と同じ形の小さな絵 (`FRAMES`、24px) と名前のチップを 1 列で横に流す (折り返さない、高さ `--tap`) (Rin0107/kisekae-closet-archive#49)。クローゼットの棚のタブも同じ形 (`KindIcon` 20px と名前、#77)
- 登録: 写真を選ぶまで「クローゼットにしまう」は押せない (disabled)。しまえたら「トップスにしまいました」を role=status の小さなカード (`.saved`) で知らせる (Rin0107/kisekae-closet-archive#49)
- 空: 服がなければ、今日の画面の棚に「まだ服がありません」と「服をしまう」ボタン。棚がからなら「この棚はからっぽです」。新しいアカウントには見本の服 (6 種類を 1 枚ずつ、`src/samples.ts`、写真は `public/samples`) が入っているので、空の棚はふつう出ない
- 読み込み中: 天気は「天気を読んでいます…」 (読めなければ 1 秒・3 秒おいて自動で 2 回まで読み直し、それでも読めなければ `role="alert"` で「天気を読めませんでした」と「もう一度読む」、#31)。写真は切り抜きができるまで元の写真。前回の予報を出している間は、天気の下に小さく「7:05の予報 (新しい予報を読んでいます)」 (読めなければ「(新しい予報を読めませんでした)」)
- 失敗: `role="alert"` で理由を 1 行。天気が読めなければ「これに決めた」を出さない (先の日で予報がなければ「この日の予報がありません」)
- 先すぎる日: カレンダーで 16 日先からの日を押すと「先すぎて、まだ天気の予報がありません (15 日先まで決めておけます)」
- できた: キラッ・スタンプ

## 文言
- 調子: です・ます。短く。ボタンは動詞 (しまう・決めた・この日のコーデにする)
- 服の暖かさ (しまうとき・棚のカード): ●の数でなく 5 つの言葉と服の例 (`WARMTH`): とても薄い=Tシャツ・薄手=シャツ・ふつう=ニット (最初)・厚手=ジャケット・とても暖かい=ダウン。ボタンは名前と例の縦 2 段のチップ。`aria-label` は「暖かさ 1〜5」のまま
- 用語: 服・コーデ・クローゼット・棚・ラベル・暖かさ・スタンプ。「着せ替えてみる」ボタンは作らない

## アクセシビリティ
- スマホの幅 (360px) で崩れない・横に流れない
- キーボードだけで操作できる (カードはボタン。ドラッグの代わりにタップ・Enter で着る)
- 文字と背景のコントラストは WCAG AA 以上。色だけで意味を伝えない (ゲージは言葉、カレンダーは凡例と aria-label)
