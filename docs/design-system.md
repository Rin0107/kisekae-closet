# kisekae-closet — デザインシステム

持ち主: **designer**。画面はここに書いたものだけで作る。変えるときは、わざと変えて理由を `## 変えたこと` に書く。

## トークン
`src/style.css` の `:root` に CSS 変数で置く。部品は生の値 (色・大きさ・余白) を書かず、変数だけを使う。
- 色 (いちごミルク): 地 `--c-bg` #fff7f9・面 `--c-surface`/`--c-surface-2`・文字 `--c-text` #3d2a30・弱い文字 `--c-muted`・強調 `--c-primary-strong` #b53b5e (白い字とのコントラスト 4.5 以上)・やさしいピンク `--c-primary-soft`・失敗 `--c-danger`。
  ゲージ `--c-cold`/`--c-ok`/`--c-hot`、カレンダーの近さ `--c-same`/`--c-near`、キラッ `--c-gold`
- 文字: system-ui (外から字を読まない)。段は `--fs-s` 0.8125 / `--fs-m` 1 / `--fs-l` 1.25rem
- 余白: `--sp-1` 0.25 / `--sp-2` 0.5 / `--sp-3` 1 / `--sp-4` 1.5rem
- 角・影・動き: `--radius` 16px・`--radius-s` 10px・`--shadow`・`--ease` (Material 3 の emphasized)・`--dur` 240ms。prefers-reduced-motion では動かさない
- 大きさ: タップは `--tap` 48px 以上。アバターの台は `--stage-w` 200px × `--stage-h` 400px、幅 768px 以上では 280px × 560px (#34)。幅 768px 以上の今日の画面は、台を左に、ゲージ・決めるボタン・棚を右に並べる (#40)。その幅の中では**固定** (どの画面でも一番大きい。中身で縮めない)

## テーマ
`src/theme.ts` の `THEMES`。いちごミルク (既定、`:root` と同じ値)・ミントソーダ・ラベンダー・ミルクティー。
色のトークン (`THEME_TOKENS`) だけを `:root` に上書きする。大きさ・余白・台の大きさは変えない。
字と地の組 (`TEXT_PAIRS`) は、どのテーマでも 4.5:1 以上 (`tests/unit/theme.test.ts`)。新しいテーマも同じ検査を通す。

## 部品
- **アバターの台** (`Stage`): 正面に固定した体の絵 (CC0 の MakeHuman の人体を Blender で描いた `public/avatar/body.webp`、400×800、背景は透明。出どころは `public/avatar/LICENSE.md`) に、切り抜いた服の写真を種類ごとの場所 (`SLOTS`) に重ねる。写真は曲げない。トップス・ワンピース・アウター・ボトムスは**幅で合わせ、縦は写真のまま** (体の絵を測った目印 `BODY` に対し、袖を除いた身ごろが胴の下着の幅と首元を覆う幅。#26)。ボトムスは丈を先に決め、裾が足首に届く幅にする (腰を覆う 46%〜太すぎない 60%、`place`、#33)。アウターはトップスより一回り大きく少し下から置き、中の服の襟元がのぞく (#33)。くつは 2 足の写真を左右の半分に切り分け、それぞれの足に履かせる (`shoeFeet`、#32)。片足の箱は足より一回り大きく (`FOOT_BOX` 16×10%、細くても足の幅を下回らない)、ボトムスの裾より前に重ねる (長ズボンでも甲が見える、#39)。トップス・アウターは写真を左の袖・身ごろ・右の袖に切り分け (`pieces`)、写真の袖の先を測って (`measureSleeve`)、袖の先が A の字の腕の外の線に来るよう付け根を中心に回す (`sleeveTurn`、-10〜40 度。写真は曲げない、#37)。中にトップスかワンピースを着ていれば、アウターは前身ごろを左右に分けて前を開ける (`OPEN_GAP`、#38)。こものは箱に収める。服が届くまでは服の場所に淡い形 (`wear-pending`) を出し、下着姿を見せない (#28)。今日の画面とカレンダーの下見で使う
- **ラベルの行** (`LabelRow`): 台の下の高さ固定 (32px) の 1 行。3 つまで、残りは「+N」。台には重ねない
- **暖かさゲージ** (`GaugeView`): 寒い・ちょうどいい・暑いの帯とつまみ。数字は出さない。服が届くまではつまみを出さず「服を読んでいます…」 (#28)
- **棚** (クローゼット): 種類のタブ (トップス・ワンピース・ボトムス・アウター・くつ・こもの。ワンピースにも自分のタブ、#35) と服のカード。カードはタップで着る・台までドラッグで着る
- **キラッ**: 着替えたとき台の上で光る 3 つの星
- **スタンプ**: コーデを決めると台の右下に「決めた!」。カレンダーの決めた日 (今日まで) には ♥、先に決めておいた日には ♡
- **先の日の帯** (`plan-bar`): 先の日のコーデを決めているあいだ、今日の画面の上に「11月20日のコーデを先に決めています (予報)」と「今日に戻る」
- **テーマの選択** (`ThemePicker`): クローゼットの画面の下。色の見本つきのボタン 4 つ (押している状態は `aria-pressed`)
- **カレンダーのマス**: 日・天気のアイコン・最高気温・湿度・スタンプ。背景色で今日との近さ (凡例つき)
- **タブバー**: 下に固定。今日・クローゼット・カレンダー
- ボタン: `primary` (主な 1 つ)・`ghost` (それ以外)・押している状態は `aria-pressed`/`aria-selected` で同じ見た目

## 状態
- 空: 服がなければ、今日の画面の棚に「まだ服がありません」と「服をしまう」ボタン。棚がからなら「この棚はからっぽです」
- 読み込み中: 天気は「天気を読んでいます…」 (読めなければ 1 秒・3 秒おいて自動で 2 回まで読み直し、それでも読めなければ `role="alert"` で「天気を読めませんでした」と「もう一度読む」、#31)。写真は切り抜きができるまで元の写真。前回の予報を出している間は、天気の下に小さく「7:05の予報 (新しい予報を読んでいます)」 (読めなければ「(新しい予報を読めませんでした)」)
- 失敗: `role="alert"` で理由を 1 行。天気が読めなければ「これに決めた」を出さない (先の日で予報がなければ「この日の予報がありません」)
- 先すぎる日: カレンダーで 16 日先からの日を押すと「先すぎて、まだ天気の予報がありません (15 日先まで決めておけます)」
- できた: キラッ・スタンプ

## 文言
- 調子: です・ます。短く。ボタンは動詞 (しまう・決めた・この日のコーデにする)
- 用語: 服・コーデ・クローゼット・棚・ラベル・暖かさ・スタンプ。「着せ替えてみる」ボタンは作らない

## アクセシビリティ
- スマホの幅 (360px) で崩れない・横に流れない
- キーボードだけで操作できる (カードはボタン。ドラッグの代わりにタップ・Enter で着る)
- 文字と背景のコントラストは WCAG AA 以上。色だけで意味を伝えない (ゲージは言葉、カレンダーは凡例と aria-label)
