# DATA — このアプリが持つ情報

このアプリは**ログインがあり、サーバーに保存するアプリ**です (持ち主の決定。工場の docs/DESIGN-v3.md §10)。
それでも**重要な情報はできるだけ持たない**。下の表にないものは、どこにも保存しない。
欄を足すときは、先にこの表を更新する (reviewer と CI が照らし合わせる。migrations/ は守りの部分)。

## サーバー (Cloudflare D1)

| テーブル       | 何を                                                                                     | なぜ                                                                    |
| -------------- | ---------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `users`        | ランダムな利用者 ID・作った時刻                                                          | 服とコーデを誰のものか分けるため。名前もメールも持たない                |
| `passkeys`     | パスキーの ID・**公開鍵**・使った回数・つなぎ方 (usb など)                               | ログインのため。秘密鍵は端末から出ない。公開鍵は漏れても誰も困らない    |
| `challenges`   | ログインの問題 (ランダム)・用途・期限 (5 分)                                             | パスキーの確かめのため。使ったら消す                                    |
| `logins`       | セッションの **SHA-256 の指紋**・利用者 ID・期限 (30 日)                                 | ログインを続けるため。Cookie の値そのものは持たない                     |
| `clothes`      | 服の写真 (Exif を消したもの、300KB まで)・種類・暖かさ (1〜5)・自分で付けた名前 (40 文字まで) | 着せ替えとおすすめのため                                                |
| `outfits`      | 着た日・その日の最高/最低気温・湿度・降水量                                              | 似た天気の日の過去のコーデを出すため。場所は持たない                    |
| `outfit_items` | コーデに入った服                                                                         | 同上                                                                    |

- 写真は端末で縮小・再エンコードし、撮った場所などの情報 (Exif・XMP) を消してから送る。サーバーでも残っていれば受け取らない (`src/worker/photo.ts`)
- 写真は本人にだけ返し、キャッシュさせない (`Cache-Control: private, no-store`)
- 「アカウントと全データを消す」で、上の行は全部消える
- 「データを書き出す」で、自分の服 (写真つき) とコーデを JSON で取り出せる

## Cookie

| 名前         | 中身                                                         | なぜ                                       |
| ------------ | ------------------------------------------------------------ | ------------------------------------------ |
| `__Host-sid` | ランダムな 32 byte (HttpOnly・Secure・SameSite=Strict・30 日) | ログインを続けるため。サーバーには指紋だけ |

## ブラウザの中だけ (localStorage)

| 何を                       | キー            | なぜ                                                                 |
| -------------------------- | --------------- | -------------------------------------------------------------------- |
| 選んだ市 (天気を読む場所) | `kisekae-closet:city` | 天気のため。サーバーには送らない (ブラウザが Open-Meteo を直接読む) |

## 外への通信

- `api.open-meteo.com` (天気)。選んだ市の代表の緯度・経度だけを送る。鍵は要らない

## 持たないもの

メールアドレス・パスワード・名前・住所・電話番号・IP アドレス・User-Agent・位置の履歴・支払い情報・解析ツールのデータ。
